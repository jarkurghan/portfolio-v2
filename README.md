# portfolio

Najmiddin Nazirov shaxsiy sayti. Next.js (App Router), React, TypeScript va Tailwind CSS. Matnlar o‘zbek, rus va ingliz tillarida.

## Ishga tushirish

```bash
bun install
bun dev
```

[http://localhost:3000](http://localhost:3000)

```bash
bun run build
bun start
```

## Tuzilma

- `app/` — bosh sahifa, ishlar, tajriba, aloqa
- `lib/content.ts` — profil, loyihalar, ish tarixi
- `lib/messages/` — `uz` / `ru` / `en` matnlari
- `components/` — interfeys

Til `locale` cookie orqali saqlanadi. Standart til — o‘zbekcha.
